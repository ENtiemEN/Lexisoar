# Pedagogía y cobertura TOEFL
Diseño propuesto, no ensayo de eficacia. El banco es de **60 actividades breves originales en borrador**: cinco temas por doce formatos. No son 60 conjuntos completos revisados.

Comprender → recuperar → producir → recibir ayuda → reintentar → repasar después. Ruta sugerida y elección libre. Completar tareas o ganar puntos no demuestra dominio.

| Decisión | Aplicación | Evidencia y límite |
|---|---|---|
| Input comprensible | Contexto, textos/audio cortos, ayudas en inglés | Nakanishi 2015; lectura extensiva no garantiza C2 |
| Recuperación | Responder antes de ver referencia | Dunlosky 2013; repetir ítem no demuestra transferencia |
| Espaciado | FSRS para vocabulario contextualizado | Kim/Webb 2022; no intervalo universal óptimo |
| Producción/feedback | Una mejora prioritaria y reintento | Lyster/Saito 2010 y Kang/Han 2015; estudios humanos no validan un LLM |
| Juego | Variedad, recompensas de esfuerzo y ruta no punitiva | Sailer/Homner 2020; motivación no equivale a aprendizaje |

| Habilidad / formato | Evidencia buscada | Implementación inicial |
|---|---|---|
| Reading: Complete the Words | Reconstrucción contextual | Palabra escrita |
| Reading: Read in Daily Life | Información de aviso | Selección |
| Reading: Read an Academic Passage | Inferencia/evidencia | Microtexto y selección |
| Listening: Listen and Choose a Response | Intención/respuesta | TTS y selección |
| Listening: Listen to a Conversation | Siguiente acción | TTS lineal; audio natural pendiente |
| Listening: Listen to an Announcement | Cambio/instrucción | Aviso TTS |
| Listening: Listen to an Academic Talk | Causa/límite | Microtexto TTS; no conferencia completa |
| Writing: Build a Sentence | Orden sintáctico | Respuesta normalizada |
| Writing: Write an Email | Propósito/registro/desarrollo | Producción y revisión |
| Writing: Write for an Academic Discussion | Posición/argumentación | Producción y revisión |
| Speaking: Listen and Repeat | Repetición/autoescucha | Grabación/transcript, sin nota acústica |
| Speaking: Take an Interview | Respuesta con ejemplo | Pregunta, grabación y revisión textual |

[ETS: contenido vigente](https://www.ets.org/toefl/test-takers/ibt/about/content.html). Escala actualizada en 2026: **1–6 con incrementos de 0,5**; [ETS: nueva escala](https://www.ets.org/toefl/institutions/ibt/score-scale-update.html). No convertir porcentaje de aciertos del prototipo en esa escala. Revalidar especificaciones antes del cierre académico.

Speaking no penaliza mayúsculas/puntuación/ortografía de ASR. El tutor recibe texto, no audio. Autoobservación: cumplimiento, claridad, ejemplo y organización. TTS no sustituye variedad de hablantes/prosodia natural. Dificultad B1–C2 es intención curricular, todavía no calibración.

Diagnóstico futuro: autopercepción y muestras independientes nuevas en las cuatro habilidades, devolviendo prioridades orientativas. Evaluación prevista: intento sin ayuda → ayuda → reintento → prueba demorada con material nuevo. Registrar retención, transferencia y errores ASR por separado. No afirmar causalidad ni eficacia sin diseño de evaluación apropiado.

Revisión del banco: objetivo concreto, exactitud, inglés natural, respuesta única, distractores plausibles, formato, autoría, ayudas y accesibilidad. Registrar revisor/fecha/versión antes de draft→reviewed. Dos simulacros futuros serán lineales y aproximados, sin replicar adaptación ETS.

Medición 0.3: [definiciones, fundamento y límites de Progress](11-incremento-0.3.md). Se separan práctica, rendimiento objetivo, observaciones del tutor y autoinforme de recuperación.


Vocabulary 0.4 incorpora recuperación receptiva/productiva y contexto, de forma independiente de historias y de las cuatro habilidades. [Fundamento, métricas y límites](12-incremento-0.4.md). Las 120 bandas orientativas y el contenido requieren revisión humana.


Grammar 0.5 combina ejemplos contrastados, explicación breve, manipulación y producción independiente. [Fundamento, catálogo y límites](13-incremento-0.5.md). No se atribuye nivel MCER por completar temas.
